Getting Started

The DaB 2D Quantity Takeoff is a high-performance utility engineered for Autodesk® AutoCAD® and Civil 3D®. It streamlines estimation workflows by accurately extracting and calculating linear lengths, surface areas, and item counts directly from your CAD drawing environment based on custom layer rules and selections.

System Requirements

  • Host Application: Autodesk® AutoCAD® or Civil 3D® (Versions 2025 through 2026+)
  • Operating System: Microsoft® Windows® 10 or 11 (64-bit / x64 Architecture Required)
  • Runtime Environment: Microsoft® .NET Desktop Runtime 8.0 (automatically managed by modern AutoCAD installations)
  • User Interface Framework: Windows Presentation Foundation (WPF) Desktop Core

Installation & Quick Launch

The utility features a fully automated installer tailored for the Autodesk® App Store environment. Upon executing the .msi package, all binaries, dependencies, and menu configurations are deployed directly into your system's secure ApplicationPlugins directory.

To initialize the program within your active CAD workspace:

  1. Launch AutoCAD® or Civil 3D® (Version 2025 or newer).
  2. Look for the newly added DaB ANY CAD Tools tab on your top AutoCAD Ribbon menu interface.
  3. Click the 2D Quantity Takeoff button icon within the ribbon panel to dynamically toggle the interface control board.
  4. Alternative Command Line Method: You can also type QTY_UTI directly into the command prompt at any time to execute the app.

Licence Management

We provide a fully functional, risk-free 3-Day Free Trial for all new users to evaluate the takeoff calculation engine. After the trial period expires, a valid license key is required to maintain access to extraction and export routines.

Activation Steps

When the application launches or when evaluating trial status, the licensing screen will display your unique, secure Hardware Fingerprint (Machine ID).

  1. Copy the generated Machine ID string directly from the prompt window or About form.
  2. Submit this ID alongside your Autodesk App Store purchase confirmation to receive your unique activation key.
  3. Paste your key into the text field and click Activate License. The utility will store this authorization locally on your device for uninterrupted usage.

Privacy Policy & Security Compliance

We prioritize your project security and design confidentiality. In strict compliance with Autodesk App Store Developer Guidelines, our software operates using a fully transparent, localized architecture.

  • Zero Data Exfiltration: We do not collect, view, store, or transmit your CAD drawing files (.dwg), design variations, project metadata, or any corporate intellectual property.
  • Secure Local Storage: All licensing preferences and system configurations are saved locally on your workstation within the secure Windows Registry hive (HKEY_CURRENT_USER\Software\DAB_ANY\2D_Quantity).
  • No Tracking: This software operates free of third-party analytics trackers, background metrics collection, or behavioral profiling scripts. Network access is strictly restricted to secure validation routines.

2. Core Operation

The Core Operation workflow dictates how users interact with the tool, define quantities, and extract datasets from the CAD workspace.

How to Use the Application

The application is activated directly from the DaB ANY CAD Tools ribbon tab or by entering the command QTY_UTI in the command line. Once launched, users are greeted with a primary mode selection offering two distinct paths:

  • Quick Option: An automated, streamlined workflow designed for instant drawing evaluation.
  • Advanced Option: A fully customizable environment granting granular control over layers, object mappings, and manual measurement workflows.

Measurable Quantities & Units

The tool processes three core engineering quantity categories, reporting values directly matching your active CAD drawing units:

  • Linear: Measures continuous lengths (e.g., curbs, pipes, fences, or polylines) reported in linear drawing units.
  • Area: Evaluates closed boundary surfaces (e.g., pavement patches, sodding, or building footprints) reported in square drawing units.
  • Count: Quantifies discrete item occurrences (e.g., manholes, signs, trees, or blocks) reported as absolute numerical quantities.

Item Import Methods

To populate your takeoff schedules, items can be brought into the application using three versatile methodologies:

  • By Object Layer: Automatically parse and group entities based on their source layer assignments in the drawing.
  • By Picking from Drawing: Manually select specific CAD objects directly from model space to include in specific calculation groups.
  • By Defining Area or Linear Objects: If source geometry does not pre-exist in the drawing, users can manually trace custom linear paths or closed area boundaries to establish new measurement items on the fly.

3. Quick Option

The Quick Option mode is designed for rapid, straightforward takeoffs directly from drawing elements without requiring complex configuration panels. When selected, the tool prompts you inside the AutoCAD command line to interact with your drawing objects.

During execution, the command prompt displays the following interactive mode prompt:

Select objects:
Add Item [Only-selected/Entire-layer] <Only-selected>:

Only-Selected

When this mode is active, Only-Selected ensures that strictly the individual items and drawing entities you manually clicked or window-selected are evaluated and added to the calculation list. Surrounding objects on the same layer are ignored.

Entire-Layer

Selecting Entire-Layer switches the scope so that once an object is picked, all matching geometry residing on that same source layer across the drawing environment is aggregated and added to the calculation dataset automatically.

Quick Result Window & Export Methods

Following object selection, the data compiles instantly into the Quantity Takeoff Results window. Adhering to professional Autodesk App Store design standards, this window features an adaptive interface with a built-in theme toggle (🌓 Theme) supporting dynamic Dark and Light workspace layouts.

The results window displays a clean data grid layout containing:

  • Layer / Item: Identifies the source layer or item description.
  • Category: Defines whether the measurement is Linear, Area, or Count.
  • Quantity / Value: Shows the calculated aggregate measurement matching current drawing scales.

At the bottom right of the window, multiple export and reporting tools are available:

  • 📐 Insert Table: Instantly generates and embeds a professional quantity schedule table directly inside your active AutoCAD drawing layout.
  • 🌐 Export HTML: Dumps the takeoff data into a clean, formatted HTML report file for sharing, archiving, or cost-estimating handoffs.
  • Close: Safely exits the result window back to the drawing workspace.

4. Advanced Option

The Advanced option grants comprehensive user control over filtering, categorization, and custom measurements.

4.1 Advanced UI Layout

The Advanced interface features a split layout: the left pane displays all available drawing layers, while the central workspace houses dedicated tabs for Linear, Area, and Count metrics alongside Add and Remove control tools.

4.2 Source & Display Columns

Inside each tab, items are categorized into two columns: Source and Display. Items assigned the exact same display name will automatically aggregate and sum their quantities together.

4.3 Item Addition Methods

Items can be added to your takeoff lists using multiple workflows:

  • By Layer: Extract elements based directly on source layer assignments.
  • From Selection: Manually pick specific entities straight from model space.
  • Manual Tracing: If no geometry exists, users can define quantities manually by tracing linear paths or closed area boundaries.

4.4 Calculation

Once your sources and display categories are fully configured, click the Calculate button to process the evaluation against the current drawing dataset.

5. Result Window

The final Result Window exhibits a structured table of all extracted quantities, categorized by type. From here, users can review final sums and export metrics for cost estimation and reporting.
